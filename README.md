# valentines-website


A tiny offline Valentine’s Day webpage to ask **Jaana** out on a movie + food date. Works by simply opening `index.html` in any modern browser.


## Features
- No backend, no external APIs, no CDNs — works fully offline.
- Mischievous NO button that fakes a loader once, then becomes impossible to click (runs away, resizes, teases).
- YES button triggers heart rain, confetti, and a romantic confirmation screen.
- Mobile-friendly, playful, pastel Valentine aesthetic.
